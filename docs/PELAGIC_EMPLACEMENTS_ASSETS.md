# Coastal cannon remnants — Task 1

Generated with the built-in ImageGen tool on 2026-11-14. Runtime assets are stored in `public/assets/arcade/pelagic-review/emplacements.png` and `public/assets/arcade/pelagic-review/gun-smoke.png`. No API fallback was used. Both preserve generated RGBA transparency; runtime registers cell frames directly at native resolution.

`emplacements.png` is 1254 × 1254, 4 columns × 4 rows. The runtime consumes the intact foundation in cell 0, destroyed foundation in cell 1 and fire cells 4–7. Cells 8–15 were rejected because some smoke drawings exceeded their cell boundaries; the second generated sheet replaces them. `gun-smoke.png` is 1774 × 887, 4 columns × 2 rows. Adjacent smoke frames crossfade, with a fixed ground contact point.

The simulation creates one wreck per destroyed land gun. Wrecks never fire or receive damage, preserve their world position, stop with the ground when scrolling stops, and leave the scene only after their smoke passes the bottom of the viewport. Gun foundations and destroyed foundations share their footprint.
